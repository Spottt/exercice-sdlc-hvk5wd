# T-142 · Changer de stand jusqu'à J-7

> Les exposants veulent pouvoir changer de stand eux-mêmes jusqu'à 7 jours avant l'ouverture du salon,
> au lieu d'appeler l'organisateur. Un gros client le veut pour son salon de janvier.
>
> — Sophie, responsable produit

Ce qu'on sait par ailleurs :

- un stand ne doit jamais être réservé par deux exposants ;
- le nouveau stand peut être plus cher ou moins cher : l'acompte (30 % du prix) doit suivre ;
- à moins de 7 jours de l'ouverture, le changement est refusé avec un message clair.

Cadre de l'exercice :

- il n'y a pas de connexion utilisateur dans cette application, et ce n'est pas à ajouter :
  l'exposant est identifié par le nom saisi à la réservation ;
- il n'y a pas de paiement non plus : on attend le bon montant d'acompte, pas un encaissement ;
- **l'API est obligatoire, le front est un plus** si le temps le permet.

Le ticket est volontairement court, comme dans la vraie vie. S'il vous manque une information,
faites une hypothèse raisonnable et écrivez-la.
